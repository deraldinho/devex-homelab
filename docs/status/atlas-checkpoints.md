## Regras de aceitação

1. **Status GREEN local** certifica somente o código e o ambiente de testes citado, nunca o backup real, uma delegação Hermes real ou o estado do Pentium.
2. **Estado do GitHub Issue #11:** a integração retornou 404; o estado administrativo remoto não foi confirmado. O backlog local foi retificado apenas quanto à **certificação operacional**.
3. **Segurança:** manter `self_healing_v1=false`, `agency_specialists.enabled=false`, permissões de CONTROL vazias e Voice pausado até os gates físicos. Nenhum dos testes aqui exige restart, deploy, branch, worktree, commit ou push.
4. **Evidência de teste:** resultado antigo vale para o código/teste da época. Alterações posteriores exigem executar novamente a suíte canônica e registrar novo resultado no HEAD local.
5. **Prioridade para implementação:** finalizar DR real e restauração; certificar CP-H12; realizar E2E Hermes isolado READ-only com autorização; só depois promover agentes; em paralelo, especificar os contratos de migração do MemoryGraph v2 antes de editar dados persistentes.
