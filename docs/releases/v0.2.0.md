# DevEx HomeLab v0.2.0 — Consciência Afetiva & Tecido Sensorial

Data de Homologação: 2026-09-20

## 1. Escopo Estável e Entregas

Esta versão marca a evolução do DevEx HomeLab da fundação operacional para a **Consciência Afetiva e Sensorial Integrada**, consolidando o papel do Atlas como mini-pet e inteligência emocional da infraestrutura homelab com background no Hermes 3.

O escopo certificado inclui:

1. **Saneamento e Resiliência de Runtime**:
   - Resolução definitiva de estouro numérico (`OverflowError`) no cálculo de backoff exponencial sob falhas contínuas de nós desligados.
   - Expurgo de registros de teste órfãos da base de memórias SQLite.
2. **Governador Afetivo Total**:
   - Matriz expandida com **20 sentimentos canônicos** calculados deterministicamente a partir de métricas de ativação, valência, estresse e novidade.
   - Injeção das diretrizes de modulação emocional no Hermes 3 via bloco `<affective_state_governor>`, impactando velocidade, cadência e estilo de fala.
   - Memória de trabalho de diálogo preservando os últimos 5 pares de mensagens (`<recent_conversation_history>`).
3. **Tecido Sensorial SSH, Telemetria L2jToren & ReAct Agent Loop**:
   - Conector observacional determinístico híbrido: sondas de rede TCP instantâneas (portas 7777, 8088, 2106, 3306, 9090, 3000) e flash query SSH (< 1.5s) com autenticação dedicada para Windows x99.
   - Suporte nativo à sintaxe do Windows PowerShell para inspeção de containers Docker l2jtoren.
   - Mapeamento das 501 métricas OpenTelemetry reais no Prometheus (`l2j_jvm_memory_heap_used_bytes`, `l2j_process_cpu_load`, etc.) e integração com a API do Grafana.
   - **ReAct Agent Loop Bounded**: Ciclo multi-passo de inferência e observação (`Thought -> Action -> Observation -> Synthesis`). O Atlas aciona as capabilities de leitura de forma assíncrona/segura e sintetiza os dados em linguagem natural antes de responder ao operador.
   - Novas capabilities allowlisted: `l2j_get_status`, `l2j_get_dashboards`, `l2j_check_jvm`, `l2j_docker_stats`, `l2j_probe_ports`, `get_cluster_vitals`, `git_get_status`, `git_recent_commits`.
4. **Motor de Consistência de Tarefas (Task Consistency Engine)**:
   - Persistência atômica contínua de tarefas em `self-work-current.json` e histórico em `self-work-history.jsonl`.
   - Suporte à recuperação no boot: se o daemon reiniciar ou sofrer preempção humana, as tarefas pendentes com TTL válido são restauradas automaticamente.
   - Capabilities canônicas de tarefas expostas ao operador e integradas ao ReAct loop: `task_status`, `task_create`, `task_complete`, `task_abandon`.
5. **Discord Gateway Aprimorado & Watchdog Proativo**:
   - Auto-chunking inteligente preservando rigorosamente a integridade de blocos de código markdown.
   - Reply nativo encadeado mantendo a linha do diálogo contextual.
   - Roteamento ativo de alertas de infraestrutura para `#🤖│watchdog` (`1476441917020700773`) com monitoramento contínuo de portas, containers e limiar de JVM Heap (>= 90%).
6. **Sonda de Logs de Containers do L2jToren (`l2j_get_logs`)**:
   - Extração segura e estruturada dos logs de containers Docker (`l2jtoren-gameserver`, `l2jtoren-loginserver`, `l2jtoren-db`, etc.) via SSH no nó x99 com tolerância a sandbox systemd (`-F /dev/null`) e captura simultânea de stdout/stderr.
7. **Estabilização de Capacity e DR**:
   - Cgroups rigorosos nos runners do Core (`core-l2jtoren-01`, `core-l2jtoren-02`, `core-homelab-01`).
   - Backup automatizado com Restic + GitHub Releases vault e verificação de drift contínua.

---

## 2. Garantias da Versão

- **Estado técnico determinístico**: A LLM nunca avalia gates de saúde nem autoriza comandos fora do Policy/Action Engine.
- **Sem shell arbitrário**: Todas as chamadas SSH utilizam comandos tipados fixos por plataforma com timeouts estritos e `BatchMode=yes`.
- **Local-first e resiliente**: O cluster mantém operação sensorial e reflexos mesmo durante falhas ou lentidões da LLM.
- **Baixo consumo de recursos**: Todos os daemons rodam contidos no Pentium Dual-Core com limites estritos de cgroup (RAM < 200MB no observation e < 400MB no cognitive).
