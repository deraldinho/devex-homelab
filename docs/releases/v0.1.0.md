# DevEx Home Lab v0.1.0 — Stable Foundation

Data alvo: 2026-09-04

## Escopo estável

Esta versão consolida a fundação operacional do Home Lab e o Atlas até a slice A5.
O escopo certificado inclui:

- rede de gerenciamento e contratos de saúde já presentes na stack;
- heartbeat e agente de status do Pentium;
- Atlas State/Reaction Foundation e Observation Runtime na ancestralidade certificada;
- A1 — Núcleo Afetivo;
- A2 — Entidades, vínculos e expectativas;
- A3 — Percepção e correlação;
- A4 — Foco e emoção derivada;
- A5 — Agente de Nó Atlas C++ multiplataforma.

## Garantias da versão

- estado técnico permanece autoritativo;
- estado afetivo nunca reclassifica saúde técnica;
- processamento afetivo determinístico, bounded e testável;
- filas e payloads do Node Agent são bounded;
- identidade local de projeto é validada;
- Named Pipe no Windows e Unix Socket no Linux;
- vitals crus do host sem threshold universal de negócio;
- nenhuma LLM escreve estado técnico ou afetivo.

## Fora desta versão

As slices abaixo continuam no roadmap e não são alegadas como concluídas pela v0.1.0:

- A6 — TCP/TLS, gRPC/mTLS e HTTPS/mTLS;
- A7 — diagnóstico ativo por ping/traceroute/SSH allowlisted;
- A8 — integração física, recuperação e certificação final da iniciativa completa;
- LLM Reaction Loop, áudio, memes, TTS/STT e autonomia de controle.

A ausência desses itens não é tratada como defeito da v0.1.0: eles não pertencem ao contrato desta versão estável.

## Gate de release

A tag `v0.1.0` só pode apontar para um SHA que cumpra simultaneamente:

- `Foundation CI` GREEN no HEAD exato;
- `Node Agent CI` GREEN em Ubuntu e Windows no HEAD exato;
- CTest do Node Agent GREEN;
- stack de testes Atlas GREEN;
- `git diff --check` GREEN contra `main`;
- árvore limpa e SHA remoto igual ao candidato;
- nenhum commit da ponta contaminada da Observation Runtime introduzido fora da ancestralidade certificada.
